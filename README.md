### 🚀 Featured Engineering Projects

#### 01. [FraudShield — Fraud Monitoring & Investigation Platform](https://github.com/dheerajkmahale/FraudShield)
> **Production-grade full-stack MERN application for monitoring financial transactions, managing fraud cases, and analyzing suspicious transaction networks.**

<p>
  <a href="https://fraud-shield-sand.vercel.app/" target="_blank"><img src="https://img.shields.io/badge/Live_Demo-fraud--shield--sand.vercel.app-00C7B7?style=flat-square&logo=vercel&logoColor=white" alt="FraudShield Live Demo" /></a>
  <a href="https://github.com/dheerajkmahale/FraudShield" target="_blank"><img src="https://img.shields.io/badge/Source_Code-FraudShield-181717?style=flat-square&logo=github&logoColor=white" alt="FraudShield Repo" /></a>
  <img src="https://img.shields.io/badge/Stack-React_|_Node_|_Express_|_MongoDB_|_JWT_|_Recharts-blue?style=flat-square" alt="Tech Stack" />
</p>

* **Rule-Based Risk-Scoring Engine:** Developed a transparent, deterministic scoring engine with 7 configurable heuristic checks (transaction amount threshold, velocity, rapid movement, repeated transfers, and geographic deviation) scoring transactions from `0` to `100`. *(Engine is rule-based; does not use machine learning)*.
* **Investigation Case Management:** Engineered full case workflows allowing investigators to open formal inquiries, record case notes, link associated transactions, and update resolution statuses.
* **Network Graph Visualization:** Interactive SVG transaction-network topology visualizing fund flows and relationships between flagged sender and receiver accounts.
* **Defense-in-Depth Security:** Enforced stateless JWT authentication, `bcrypt` password encryption (12 salt rounds), Role-Based Access Control (`Admin`, `Investigator`, `Analyst`), NoSQL injection sanitization (`express-mongo-sanitize`), input validation (`express-validator`), and API rate limiting (`express-rate-limit`).
* **API Documentation & Performance:** Documented 25 backend REST API routes using OpenAPI / Swagger (`/api/docs`). Implemented MongoDB aggregation pipelines for dashboard KPI metrics and client-side CSV data export.
* **Automated Testing & Deployment:** Built 34 automated unit and integration tests across Jest (backend) and Vitest (frontend). Deployed frontend on Vercel and backend API on Render with MongoDB Atlas.

#### 02. [ArtifactVault — AI-Powered Artifact Digitization Platform](https://github.com/dheerajkmahale/ArtifactVault)
> **Full-stack cultural heritage digitization platform combining multimodal vision AI, vector embeddings, and interactive 3D WebGL graphics.**

<p>
  <a href="https://artifact-vault-teal.vercel.app/" target="_blank"><img src="https://img.shields.io/badge/Live_Demo-artifact--vault--teal.vercel.app-00C7B7?style=flat-square&logo=vercel&logoColor=white" alt="ArtifactVault Live Demo" /></a>
  <a href="https://github.com/dheerajkmahale/ArtifactVault" target="_blank"><img src="https://img.shields.io/badge/Source_Code-ArtifactVault-181717?style=flat-square&logo=github&logoColor=white" alt="ArtifactVault Repo" /></a>

* **Multimodal Vision Classification:** Integrated Google Gemini 2.5 Flash Vision (`@google/genai` SDK) to analyze uploaded 2D artifact photographs, extracting structured taxonomy: artifact category, historical era, geographic origin, material composition, physical condition state, and model confidence score.
* **Semantic Similarity Search:** Generated 3072-dimensional text embeddings from curatorial descriptions using Gemini (`gemini-embedding-001`) and executed server-side cosine similarity comparisons to rank and discover kindred relics in the vault.
* **Curator Verification Protocol:** Implemented an "AI Suggests, Human Confirms" workflow enabling authorized curators to inspect, modify, and officially verify AI predictions before archival cataloging.
* **Interactive 3D WebGL Canvas:** Integrated Three.js with OrbitControls, multi-angle studio illumination, and wireframe mesh inspection modes for client-side spatial artifact exploration.
* **Archival Reporting & Media Pipeline:** Generated downloadable one-page museum catalog cards via `jsPDF` and handled multi-format image streaming to Cloudinary. Secured with stateless JWT authentication and `bcrypt` password hashing; deployed on Vercel and Render.

#### 03. [DeepTrace — Deepfake Video Forensic Analysis](https://github.com/dheerajkmahale/DeepTrace-Forensic)
> **End-to-end facial deepfake video forensic analysis system combining spatial feature extraction, temporal sequence modeling, and attention explainability.**

<p>
  <a href="https://deeptrace-forensics.streamlit.app/" target="_blank"><img src="https://img.shields.io/badge/Live_Demo-deeptrace--forensics.streamlit.app-FF4B4B?style=flat-square&logo=streamlit&logoColor=white" alt="DeepTrace Live Demo" /></a>
  <a href="https://github.com/dheerajkmahale/DeepTrace-Forensic" target="_blank"><img src="https://img.shields.io/badge/Source_Code-DeepTrace--Forensic-181717?style=flat-square&logo=github&logoColor=white" alt="DeepTrace Repo" /></a>
  <img src="https://img.shields.io/badge/Stack-Python_|_TensorFlow_|_OpenCV_|_Streamlit_|_Pytest-orange?style=flat-square" alt="Tech Stack" />
</p>

* **Spatio-Temporal Hybrid Neural Architecture:** Designed a TimeDistributed 4-Block CNN feature extractor coupled with a Bidirectional LSTM (BiLSTM) and a custom Temporal Attention pooling layer in TensorFlow to detect both micro-level spatial boundary artifacts and inter-frame motion inconsistencies across 10-frame sequences.
* **OpenCV Preprocessing Pipeline:** Automated facial sequence extraction using OpenCV Haar cascades with 25% margin padding, normalized to `(10, 128, 128, 3)` tensors scaled to `[-1, 1]`, with browser-safe WebM transcoding.
* **Calibrated Decision Boundary:** Locked validation-calibrated decision threshold ($\tau^* = 0.39$) to counteract extreme class imbalance (8.5:1 ratio on Celeb-DF v2) and eliminate default 0.5 classification bias.
* **Forensic Workspace & Explainability:** Deployed an interactive Streamlit forensic suite displaying temporal attention curves ($\alpha_t$) highlighting peak manipulation moments, dual-gauge confidence intervals, three-way verdicts (Authentic / Inconclusive / Deepfake), keyframe evidence inspector, and exportable JSON/HTML forensic audit reports. Covered by 57 automated pytest tests.
